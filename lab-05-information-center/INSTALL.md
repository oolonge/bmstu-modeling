# Инструкция по установке и запуску

## Требования

- Python 3.6 или выше
- PyQt5

## Установка

### 1. Установка Python

Убедитесь, что Python 3.6+ установлен:

```bash
python --version
```

или

```bash
python3 --version
```

### 2. Установка зависимостей

Установите PyQt5:

```bash
pip install PyQt5
```

или

```bash
pip3 install PyQt5
```

## Запуск приложения

### Запуск GUI приложения

```bash
cd lab5
python main.py
```

или

```bash
cd lab5
python3 main.py
```

### Запуск тестов (без GUI)

Базовый тест:
```bash
cd lab5
python test_model.py
```

Тест различных сценариев:
```bash
cd lab5
python test_scenarios.py
```

## Использование приложения

1. **Запустите приложение** - откроется главное окно
2. **Настройте параметры**:
   - Количество клиентов (по умолчанию 300)
   - Параметры генератора клиентов (среднее ± погрешность)
   - Параметры каждого оператора через выпадающий список
   - Параметры каждого компьютера через выпадающий список
3. **Настройте связи** (опционально):
   - Нажмите кнопку "Настроить связи"
   - Добавьте/удалите операторов и компьютеры кнопками +/−
   - Перетащите точки от операторов к компьютерам
   - Кликните по линии для удаления связи
   - Нажмите "Сохранить"
4. **Запустите моделирование** - нажмите кнопку "Запустить моделирование"
5. **Просмотрите результаты**:
   - Вероятность отказа
   - Статистика по каждому накопителю
   - При необходимости повторите эксперимент

## Возможные проблемы

### PyQt5 не устанавливается

Попробуйте установить через pip с флагом --user:
```bash
pip install --user PyQt5
```

### Приложение не запускается

1. Проверьте, что PyQt5 установлен:
   ```bash
   python -c "import PyQt5; print('PyQt5 OK')"
   ```

2. Убедитесь, что вы находитесь в директории lab5:
   ```bash
   cd lab5
   python main.py
   ```

### Тесты не запускаются

Убедитесь, что вы запускаете тесты из директории lab5:
```bash
cd lab5
python test_model.py
```

## Поддержка

При возникновении проблем проверьте:
1. Установлен ли Python 3.6+
2. Установлен ли PyQt5
3. Запускаете ли вы из правильной директории (lab5/)
