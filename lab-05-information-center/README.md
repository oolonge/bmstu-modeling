# Лабораторная работа №5: Моделирование информационного центра

## Описание задачи

Моделирование работы информационного центра с использованием **событийного подхода**.

### Условие

В информационный центр приходят клиенты через интервал времени **10 ± 2 мин** (равномерное распределение).

Если все три имеющихся оператора заняты, клиенту **отказывают в обслуживании**.

Операторы имеют разную производительность:
- **Оператор 1**: 20 ± 5 мин (самый производительный)
- **Оператор 2**: 40 ± 10 мин
- **Оператор 3**: 40 ± 20 мин

Клиенты выбирают свободного оператора с **максимальной производительностью**.

Полученные запросы сдаются в накопитель (очередь), откуда выбираются на обработку:
- **Компьютер 1**: обрабатывает запросы от операторов 1 и 2 за **15 мин** (детерминированное время)
- **Компьютер 2**: обрабатывает запросы от оператора 3 за **30 мин**

Необходимо смоделировать процесс обработки **300 клиентов** и определить **вероятность отказа**.

## Событийный подход

### Типы событий

1. **CLIENT_ARRIVAL** - прибытие клиента
2. **OPERATOR_FINISH** - окончание обработки оператором
3. **COMPUTER_FINISH** - окончание обработки компьютером

### Алгоритм

1. Очередь событий сортируется по времени
2. Извлекается ближайшее событие
3. Обрабатывается событие:
   - **Прибытие клиента**: поиск свободного оператора с максимальной производительностью
   - **Окончание работы оператора**: добавление запроса в очередь к соответствующему компьютеру
   - **Окончание работы компьютера**: взятие следующего запроса из очереди
4. Планируются новые события
5. Повтор до обработки N клиентов

## Возможности приложения

### Главное окно

- Настройка параметров моделирования (количество клиентов)
- Настройка параметров генератора клиентов (среднее ± погрешность)
- Настройка параметров каждого оператора (выбор через выпадающий список)
- Настройка параметров каждого компьютера (время обработки)
- Кнопка "Настроить связи" для открытия окна конфигурации топологии
- Кнопка "Запустить моделирование"

### Окно настройки связей

- Визуальное отображение операторов и компьютеров
- **Drag-and-drop** для создания связей: перетащить точку от оператора к компьютеру
- Удаление связей: клик по линии
- Кнопки **+/−** для добавления/удаления операторов и компьютеров
- Валидация: все операторы должны быть соединены с компьютером

### Окно результатов

- Вероятность отказа в обслуживании
- Общее количество клиентов
- Количество отклонённых клиентов
- Статистика по накопителям (выбор через выпадающий список):
  - Максимальная длина очереди
  - Средняя длина очереди
- Кнопка "Повторить эксперимент"

## Особенности реализации

### Производительность оператора

Производительность рассчитывается как **1 / среднее_время_обработки**.

Оператор с меньшим средним временем обработки имеет **более высокую производительность**.

### Равномерное распределение

Параметры задаются как **"среднее ± погрешность"** и преобразуются в интервал **[a, b]**:
- a = среднее - погрешность
- b = среднее + погрешность

### Гибкая конфигурация

Система поддерживает **произвольное количество** операторов и компьютеров.

Связи между операторами и компьютерами настраиваются в графическом интерфейсе.
