## Откуда берется формула 2.7 для нормального распределения

Формула 2.7 основана на **Центральной предельной теореме (ЦПТ)**, которая утверждает, что сумма большого числа независимых одинаково распределенных случайных величин приближается к нормальному распределению.

### Математическое обоснование:

1. **Исходные данные**: У нас есть n равномерно распределенных случайных величин R₁, R₂, ..., Rₙ (каждая от 0 до 1)

2. **Свойства равномерного распределения R[0,1]**:
   - Математическое ожидание: E[Rᵢ] = 0.5
   - Дисперсия: Var[Rᵢ] = 1/12

3. **Сумма n случайных величин**:
   - Сумма: S = Σ Rᵢ
   - Математическое ожидание суммы: E[S] = n × 0.5 = n/2
   - Дисперсия суммы: Var[S] = n × 1/12 = n/12

4. **Центрирование и нормирование**:
   ```
   Z = (S - n/2) / √(n/12) = √(12/n) × (Σ Rᵢ - n/2)
   ```
   Эта величина Z имеет стандартное нормальное распределение N(0, 1)

5. **Преобразование к нужным параметрам**:
   Чтобы получить нормальное распределение с параметрами (m, σ²):
   ```
   T = σ × Z + m = σ√(12/n) × (Σ Rᵢ - n/2) + m
   ```

**Практическое значение n=12**: Выбирается именно 12, потому что √(12/12) = 1, что упрощает формулу!

## Формулы для других распределений

Из лекций и отчета я нашел формулы для различных распределений:

### 1. **Равномерное распределение R[a, b]**
```
Tᵢ = a + (b - a) × R
```
где R — псевдослучайное число [0, 1]

**Обоснование**: Прямое преобразование функции распределения F(x) = (x-a)/(b-a)

### 2. **Экспоненциальное распределение** (параметр λ)
```
Tᵢ = -(1/λ) × ln(1 - R)
```

**Обоснование**: Метод обратных функций. Функция распределения F(x) = 1 - e^(-λx), откуда R = 1 - e^(-λT), следовательно T = -(1/λ)ln(1-R)

### 3. **Нормальное распределение N(m, σ²)**
```
Tᵢ = σ√(12/n) × (Σ Rᵢ - n/2) + m
```
При n=12:
```
Tᵢ = σ × (Σ₁²Rᵢ - 6) + m
```

### 4. **Распределение Эрланга** (параметры k, λ)
```
Tᵢ = -(1/(k×λ)) × Σᵏᵢ₌₁ ln(1 - Rᵢ)
```

**Обоснование**: Распределение Эрланга — это сумма k независимых экспоненциально распределенных величин

## Общий метод для произвольных распределений

Существует два основных метода:

### **Метод обратных функций** (наиболее универсальный):
1. Имеем функцию распределения F(x)
2. Генерируем R ∈ [0, 1]
3. Находим T = F⁻¹(R)

Этот метод работает, если можно найти обратную функцию F⁻¹.

### **Метод исключения (rejection method)**:
Используется когда обратная функция сложна или не существует в явном виде.
